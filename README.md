# AI Vision Companion – AI-Powered Assistive Application

AI Vision Companion is an AI-powered assistive application designed to support blind and visually impaired people in their daily lives. It uses computer vision to detect objects and understand the user's surroundings, providing real-time audio feedback through text-to-speech technology.

The application also includes text recognition (OCR) to read printed documents and newspapers aloud, voice commands for hands-free interaction, and scene descriptions to help users better understand their environment.

**Key Features**
- Real-time object detection and audio feedback
- Text recognition and reading aloud using OCR
- Voice-controlled, hands-free interaction
- Scene understanding and environmental descriptions
- Accessible and user-friendly interface

**Technology Stack:** React.js, Vite, JavaScript, Computer Vision, OCR, and Text-to-Speech.

**Goal:** To promote greater accessibility, independence, and confidence for blind and visually impaired individuals through AI technology.
